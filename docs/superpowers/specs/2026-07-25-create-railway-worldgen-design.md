# Бесконечная железнодорожная сеть для Create — дизайн

Дата: 2026-07-25
Статус: утверждён к планированию

## Задача

Мод генерирует в мире бесконечную сеть железных дорог на путях Create
(`TrackBlock`), пригодную для езды поездов Create. Сеть состоит из двухпутных
магистралей, образующих сетку, и однопутных ответвлений к станциям.
Пути имеют мягкий продольный профиль без резких перепадов: перепады рельефа
берутся насыпями, эстакадами на опорах, выемками, тоннелями и мостами.

## Платформа

| Параметр | Значение |
|---|---|
| Minecraft | 1.20.1 |
| Загрузчик | Forge |
| Зависимости | Create 0.5.1, Create: Steam 'n' Rails 1.6.x |
| Java | 17 |
| Сборка | ForgeGradle, Parchment mappings |

Steam 'n' Rails — жёсткая зависимость: из него берутся материалы путей и
декоративные элементы (фермы, семафоры на поздних фазах).

## Ключевое техническое ограничение

Путь Create — не просто блок. `TrackBlock` хранит связи в `TrackBlockEntity`,
а езда возможна только когда участок зарегистрирован в `TrackGraph`.
Worldgen-фича при этом видит только свой чанк и не имеет права трогать соседние,
тогда как связь и `BezierConnection` физически живут в BlockEntity **обоих**
концов участка.

Отсюда — разделение на два этапа, которое определяет всю архитектуру.

## Архитектура

### Этап 1 — `RailwayFeature` (worldgen)

Регистрируется через BiomeModifier (JSON) на наземные биомы Overworld,
стадия декорации `TOP_LAYER_MODIFICATION` — после рельефа и структур.

Ответственность: поставить **блоки**, и только блоки.
Насыпь, полотно, `TrackBlock` с вычисленным `TrackShape`, опоры, свод тоннеля,
пролёты моста. Никаких связей между чанками, никакой зависимости от соседей.
Результат — чистая функция от сида мира и координат чанка.

### Этап 2 — `RailwayGraphLinker` (пост-обработка)

Слушает `ChunkEvent.Load` на серверной стороне. Для чанка, ещё не помеченного
как сшитый, обходит track-блоки и вызывает

```java
TrackPropagator.onRailAdded(level, pos, state)
```

Граф сшивается сам, включая границы чанков, — здесь уже полноценный
`ServerLevel` с загруженными соседями. Признак «чанк сшит» хранится в данных
чанка, чтобы не повторять работу при каждой загрузке.

### Разделение ответственности

| Класс | Делает | Знает о |
|---|---|---|
| `RailNetwork` | чистая математика: где проходят линии | сид, координаты |
| `TrackProfiler` | продольный профиль высоты с ограничением уклона | `ChunkGenerator` |
| `TrackBuilder` | укладка полотна и рельсов на готовый профиль | `WorldGenLevel` |
| `SupportBuilder` | насыпи, опоры, эстакады, мосты | `WorldGenLevel` |
| `TunnelBuilder` | выемки, порталы, свод, освещение | `WorldGenLevel` |
| `StationBuilder` | станции в конце ответвлений | `WorldGenLevel` |
| `RailwayFeature` | оркестрация этапа 1 | всё вышеперечисленное |
| `RailwayGraphLinker` | регистрация в `TrackGraph` | `ServerLevel`, Create API |

`RailNetwork` и `TrackProfiler` не трогают мир и покрываются юнит-тестами
без запуска Minecraft. Это основная защита от регрессий геометрии.

## Геометрия сети

`RailNetwork` — класс без состояния.

**Магистрали.** Линия вдоль Z имеет базовую координату `X = k·S`, где `S` — шаг
сетки, по умолчанию 768 блоков. Симметрично для линий вдоль X.

**Джиттер.** Фактическая координата смещается низкочастотным детерминированным
шумом:

```
x = k·S + noise(seed, k, z) · A
```

где `A` = 48 блоков, период шума ~400 блоков. Путь плавно виляет, изломы
укладываются диагональными формами (`PD`/`ND`). Джиттер обнуляется в
окрестности ±64 блока от перекрёстка, чтобы линии сходились предсказуемо.

**Перекрёстки.** В точках встречи линий генерируется развязка на формах `CR_*`.

**Колейность.** Магистраль — два пути с межпутевым расстоянием 3 блока на общей
насыпи. Ответвления — однопутные, отходят от магистрали стрелкой.

**Ответвления.** Отходят к узловым точкам, размещённым детерминированно на
полусетке (шаг `S/2`) с разбросом. В конце каждого — станция.

## Продольный профиль

`TrackProfiler` строит высоту пути так:

1. Семплирует `ChunkGenerator.getBaseHeight()` вдоль линии на ±256 блоков.
   Это не вызывает генерацию соседних чанков.
2. Сглаживает скользящим средним.
3. Прижимает результат к максимальному уклону 1:12.

Уклон набирается редкими одиночными `ascending`-блоками (собственный подъём
Create — 1:1) с длинными горизонтальными полками между ними. Плавные
безье-уклоны — отдельная поздняя фаза, если ступени окажутся некрасивыми.

## Инженерные сооружения

Решение принимается по разнице «профиль минус поверхность земли»:

| Разница | Сооружение |
|---|---|
| 0…+3 | насыпь из гравия и камня со скошенными откосами |
| +4…+24 | эстакада на опорах из брёвен с раскосами, шаг опор 8 блоков |
| более +24, либо под путём вода | капитальный мост: опоры до дна, фермы |
| −1…−6 | выемка со скошенными бортами |
| менее −6 | тоннель: портал, свод, освещение |

Габарит тоннеля: 3×4 для однопутного участка, 6×4 для двухпутного.

**Вода.** Мост строится всегда, независимо от длины пролёта — сеть обязана
оставаться связной, в том числе через океаны.

**Расчистка.** Над полотном вырубается габарит: 4 блока по высоте и 1 блок
запаса по бокам, вместе с растительностью.

## Станции

В конце каждого ответвления — блок `Station` из Create, перрон и небольшое
здание вокзала, размещаемое как structure NBT. Сигналы, разъезды и готовые
поезда в этот дизайн не входят.

## Конфигурация

Forge config, серверная секция:

`gridSpacing` (768), `jitterAmplitude` (48), `maxGradeRun` (12),
`viaductMaxHeight` (24, выше — капитальный мост), `tunnelMinDepth` (6),
`supportSpacing` (8),
`mainlineDoubleTrack` (true), `branchesEnabled` (true), `stationsEnabled` (true).

## Тестирование

- Юнит-тесты `RailNetwork`: детерминированность (одинаковый сид и координаты —
  одинаковый результат), непрерывность линии через границы чанков, корректность
  геометрии перекрёстков.
- Юнит-тесты `TrackProfiler`: уклон нигде не превышает предел, профиль
  непрерывен на стыке участков.
- Ручная проверка в игре: слепок фиксированного сида, облёт магистрали на
  10 000 блоков, проверка что поезд Create проходит участок без разрыва графа.

## Ограничения

Мод действует только на вновь генерируемые чанки. В уже существующем мире
железные дороги появятся лишь в неисследованных областях.

## Фазы

1. **Фаза 1.** Сетка магистралей с джиттером, профиль высоты, насыпи, выемки,
   мосты, тоннели, опоры, сшивание графа. Ответвления к собственным станциям.
   Результат — играбельная бесконечная сеть.
2. **Фаза 2.** Ответвления к настоящим ванильным деревням: позиции вычисляются
   арифметически из `RandomSpreadStructurePlacement` плюс дешёвая проверка
   биома через `BiomeSource.getNoiseBiome()`, без генерации чанков.
3. **Фаза 3.** Косметика и режим работы сети: безье-кривые вместо ступеней,
   сигналы Create, разъезды, декор Steam 'n' Rails.

Каждая фаза получает собственный план реализации.
